# Фотоискатель

Отдельное статическое мобильное веб-приложение для поиска удачного кадра. Не
подключено к интерфейсу и логике облигационного портфеля.

## Запуск

Откройте эту папку через локальный HTTPS-сервер или опубликуйте её как статический
сайт. Например, при установленном Python запустите в этой папке:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Доступ к камере требует HTTPS или `localhost`.
Для модели и WASM-файлов нужен интернет при первой загрузке.

## Что умеет

- Находит людей и предметы в живом видеопотоке моделью MediaPipe EfficientDet
  Lite0; рисует рамку и предлагает сместить телефон, чтобы расположить объект
  около точки третей.
- Оценивает доступный свет, засветку, резкость и уровень горизонта; предлагает
  подойти ближе/отойти, выровнять телефон и скорректировать экспозицию.
- Проверяет реальные возможности камеры. Автоматически регулирует экспокоррекцию
  лишь при её поддержке; ручной режим ISO и выдержки открывает только если
  браузер и устройство подтверждают поддержку этих параметров.
- Снимает фото с максимальным разрешением, которое даёт Image Capture API, или
  делает снимок из видеопотока в качестве резервного варианта.
- Хранит снимки в IndexedDB браузера, позволяет применить фильтры и настроить
  экспозицию, контраст и цвет, сохранить обработанную копию.

Объектная модель ищет распространённые категории (например, человека, животное,
велосипед или предмет) — она не распознаёт «красоту» сцены и не знает, что есть
вокруг камеры вне текущего кадра. Эстетическая оценка — эвристика, которая
помогает перестроить видимый кадр, но не заменяет фотографа. ISO и выдержка
доступны не всем браузерам: поддерживаемые свойства зависят от телефона и его
браузера.

Модель загружается из CDN и работает на устройстве. По документации MediaPipe,
изображения не отправляются сервису; пакет может отправлять Google метрики
использования API. [Уведомление MediaPipe](https://www.npmjs.com/package/@mediapipe/tasks-vision).

Интерфейс использует ограниченную палитру, пиксельные маркеры и прямоугольную
типографику в духе [Pyxel](https://github.com/kitao/pyxel). Камера и редактор
остаются обычным веб-приложением: оно использует браузерные API доступа к камере,
а не запускает игровой Python-движок Pyxel.
